# kaalaman (pagtubos)
kaalaman (pagtubos) or `knowledge (redemption)` is a an era of adapting new habits such as daily note taking and creating a second brain. Just like the previous kaalaman, it will use the same note-taking method called [Zettelkasten](https://zettelkasten.de/) by Niklas Luhmann.

The previous kaalaman files will be removed to restart the second brain. But some resources might stay.

Once the adapting period of this new note taking habit is done and it becomes second nature, kaalaman (pagtubos) located at `new_era` branch will be rebased on `master` and will return to its original name `kaalaman`.
